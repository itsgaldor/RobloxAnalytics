Instrucciones de instalación

1 Habilitar HTTP Requests

En Roblox Studio → Game Settings → Security → Allow HTTP Requests → activar ✓

2 Insertar el Script

Explorer → ServerScriptService → Click derecho → Insert Object → Script

Renombrar a: PeruCityAnalytics

Pegar el código copiado y guardar.

3 Publicar el juego

File → Publish to Roblox (o Ctrl+P)

4 Verificar en Studio

Entrá al juego. En el panel de Output de Studio debería aparecer:
